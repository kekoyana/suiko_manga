# 水滸伝 漫画書庫

中国の古典『水滸伝』を、日本語のフルカラー漫画で読む書庫です。ChatGPTで脚本・画像を制作し、作者が確認して公開しています。

[漫画を読む](https://kekoyana.github.io/suiko_manga/)

第1〜31回、全1,123ページを収録しています。百二十回本の全120回を順次制作・追加します。第32回以降は制作中です。

「回を選ぶ」から各回を開けます。横読み・縦読み・拡大に対応し、読書位置から続きを読めます。

追加ペース：直近は1日約2〜4回（2026年10月13〜14日の実績）。画像生成の上限などにより変動します。
