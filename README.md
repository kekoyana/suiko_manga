# 水滸伝 漫画書庫

静的な画像版漫画リーダーです。第1〜23回の完成済み814ページと、第24回の1〜67ページを合わせた881ページを収録しています。第24回は一部公開で、続きは制作中です。百二十回本の全120回を順次制作・追加します。第25〜120回は準備中です。

## Cloudflare Pages の Git 連携設定

- リポジトリ: `kekoyana/suiko_manga`
- 本番ブランチ: `main`
- フレームワーク: なし
- ビルドコマンド: 空欄
- ビルド出力ディレクトリ: `public`

`public/` 内だけが公開用ファイルです。PDFは含みません。

Cloudflare Pages でリポジトリへのアクセスを許可し、上記の設定で接続してください。
