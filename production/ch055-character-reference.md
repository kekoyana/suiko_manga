# 第55回人物基準

- 宋江：小柄、短黒口顎髭。平服は灰紫無地低布頭巾灰紫袍。戦装は金甲、水銀盔、赤巾、桃花斑馬。本人LEFT頬のみ小流刑印。鼻が画面右なら見えるRIGHT頬に印なし。
- 呼延灼：金兜黄巾、黒金甲、短黒顎髭。双八稜鋼鞭は硬い直線の節付き金属棒2本、平坦な鈍い先端、刀の刃・柔らかい鞭ではない。踢雪烏騅は全黒毛で額鼻白斑なし、四足先のみ白。
- 韓滔：銅兜赤巾、茶金甲、短黒口顎髭、茶馬、長い棗木槊。黄色頭巾にしない。
- 彭玘：銀兜青巾、青銀甲、小黒口髭短顎髭、黄花馬、三尖両刃刀。
- 秦明：頑丈中年濃眉短黒髭、羽なし銀鉄兜、銀鎖甲赤袍、茶馬。狼牙棒は長く太い円筒頭に短い棘、多数。球形メイスにしない。
- 林沖：白羽宝兜、銀甲、白花袍、白灰馬、短黒髭。長柄蛇矛は穂先一本、細長く緩く波打つ。三叉・薙刀ではない。
- 花栄：若い成人端整無髭、青緑金刺繍衣、青緑頭巾に金環二つ、軽鋼甲、白馬、普通の長槍、弓と箙。三尖両刃刀にしない。
- 扈三娘：成人女性、赤衣銀鎖甲金簪、刀二本、白灰馬青いたてがみ、紅錦套索二十四金鉤。
- 孫立：淡黄肌濃い頬髭、黒鉄兜赤抹額、紺衣黒鉄甲、黒馬。槍と一条の竹節虎眼鋼鞭。呼延灼と黄赤頭巾・一本二本で区別。
- 呉用：白袍黒縁、白九綸巾、羽扇。公孫勝：星冠、青霞紋九霞衣、長黒髭、松紋剣。
- 黒旋風：非常に濃い黒褐色肌、顔首耳全腕両手すべて濃く、短縮黒髪密黒髭、粗黒衣双斧。他人の肌を暗くしない。

梁山軍は梁旗。官軍は高旗（必要なら呼延旗）。官軍の彭玘や韓滔の背後に梁旗を入れない。梁山側に黄頭巾黒金甲の呼延灼風人物を混入させない。
