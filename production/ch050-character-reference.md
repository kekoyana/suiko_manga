# 第50回の継続用人物基準

宋江：灰紫無地服・布頭巾・短口顎髭。本人左頬だけ黒二本印。正面は画面右頬、鼻が画面右向きなら見える右頬は無印。
林沖：白羽宝兜・銀甲・白花袍・白灰馬・長柄蛇矛。欒廷玉：白羽黒鉄兜・紺鎧・黒マント・長黒髭・黒馬・槍と飛鎚。
孫立：平時紺頭巾・紺衣・濃い頬髭・淡黄肌。戦時は羽なし黒鉄兜に紺布結び・紺衣鉄甲・黒馬・槍と硬い鉄鞭。
祝龍：赤羽黒鉄兜・暗色甲・黒馬・槍。祝虎：銅兜・茶衣暗色甲・茶馬・大刀。祝彪：赤頭巾・赤衣暗色甲・茶馬・槍・短口顎髭。
花栄：青緑金刺繍衣・青緑頭巾に金環二つ・無髭・白馬・弓と槍。穆弘：紺頭巾紺衣・短髭・黒馬・槍。
楊雄：赤衣紺帯・黒結髪小緑花・細髭・首青花刺青・茶馬・槍。石秀：黒頭巾灰衣短黒髭、花なし。
解珍：成人長身・紫褐肌・長顔細腰広肩・紫頭巾・短口顎髭、虎皮上衣豹皮袴・鉄三叉。解宝：成人長身でやや低く太い・濃茶肌丸顔・緑頭巾・短口顎髭、子供にしない。
楽和：若い成人・美男無髭・小黒役人帽・青緑長衣。顧大嫂：成人太身丸顔・太眉大眼・黒高髷金簪金腕輪・葡萄酒赤衣紺帯・短刀二本、後頭部こぶなし。
孫新：若い成人長身強壮・短黒髭・茶頭巾茶衣黒帯・鞭と槍。鄒淵：成人中年角顔・短黒髭・紺頭巾紺布衣革帯、鎧なし。鄒潤：成人長身細面・短口顎髭・黒髷で頭巾なし・後頭部の大きい肌色こぶ一つ・深緑衣帯。こぶは鄒潤だけ。
楽大娘子：成人女性・青灰長衣白帯・黒髷銀簪、駕籠でなく車。
扈成：成人紳士・翠緑金刺繍衣金帯・黒髷小金冠・短口顎髭。扈三娘：成人赤衣銀鎖甲金簪・刀二本・白灰馬青たてがみ。
裴宣：中年太身丸顔・小金四角飾りの黒筒帽・茶記録官衣・短口顎髭。蕭譲：青灰学者衣黒筒帽・短尖黒髭。金大堅：茶布頭巾黄土衣・頑丈な職人黒髭。侯健：濃い肌細顔・紺頭巾紺仕立衣・小口髭だけ顎髭なし・針袋。
