# 第56回人物基準

- 宋江：小柄、灰紫無地の低い布頭巾と灰紫無地袍、短黒口顎髭。本人LEFT頬だけ小黒流刑印。鼻画面右なら見えるRIGHT頬は無印。
- 呉用：白袍黒縁、白九綸巾、整黒口顎髭、羽扇一つ。
- 晁蓋：黒茶無地巻頭巾、黒茶無地袍、密黒髭、普通黄褐肌。
- 湯隆：痘痕散る黄褐肌、短黒口顎髭、黒丸フェルト帽、茶無地服黒革帯。黒旋風と混同しない。
- 林沖：短黒髭、白花袍と灰白低布頭巾、銀甲は武装時のみ。旧友徐寧とは別人。
- 徐寧：成人30代、端整な白め黄褐肌、細黒口髭と短い小顎髭、切れ長の目、髷に黒い四角布巾。自宅は落着いた緑青無地袍。宮中勤務は紫繍円領袍、官緑裏衣、錦帕、金帯、金槍。追跡の旅は緑青無地袍、灰褐外套、黒布巾、麻鞋、腰刀と朴刀。
- 徐寧の妻：成人30代、茶黒髪の宋代髷、落着いた桃茶衣と青緑裳。息子は6〜7歳、淡青衣、小さな髷。侍女二人は成人、梅香は淡黄衣、もう一人は淡緑衣。就寝も全員衣服あり。
- 時遷：痩せ小柄、黄褐肌、大きく鋭い目、薄黒口髭のみ顎髭なし、焦茶低布頭巾、焦茶旅服。夜は暗い焦茶服。超能力的跳躍や鼠そのものにしない。追跡で脚に白い包帯（負傷のふり）。
- 戴宗：痩せ長顔短黒口顎髭、杏黄旅服、黒巻紗巾小翠花、甲馬は足に小札で徒歩、実馬なし。
- 楽和：若い成人、無髭、端整で細身。旅の李榮役は青灰客商袍、紺の布帽、茶帯。
- 凌振：黄褐肌、短黒口髭小黒顎髭、藍低布頭巾、藍袍革胴当て赤茶帯。
- 彭玘：青巾青衣青銀甲、小黒口髭短顎髭。
- 雷横：頑丈黄褐肌茶巾茶衣短黒髭。

鎧の賽唐猊は雁翎のような細片が重なり金輪で繋ぐ軽い鎖子甲。匣は紅羊皮、白線と緑雲如意・獅子滾繍球の刺繍。15頁で戴宗は甲本体を持ち山へ帰る。16頁以降時遷の匣は空。甲と匣が一緒に旅を続ける誤描写を避ける。

鉤鎌槍は長い木柄に直線の槍先と小さい横鉤のある古式長兵器。56回では槍法の具体動作や連環馬撃破は描かない。徐寧は盗難・詐欺・薬による強制移送・なりすまし強盗の被害者。本人の抗議と家族への不安を保つ。
