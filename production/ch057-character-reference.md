# 第57回人物基準

宋江・呉用・徐寧・湯隆・戴宗・凌振は第56回人物基準、呼延灼・韓滔・秦明・花栄・扈三娘・孫立・水軍は第55回人物基準を継承。
徐寧は青緑無地袍と黒角形布巾、湯隆は黒丸フェルト帽と茶無地袍、痘痕・短い口顎髭を維持。
宋江は灰紫無地低布頭巾・袍、本人LEFT頬のみ小黒流刑印。鼻画面右向きで見える本人RIGHT頬無印。
官軍高旗、梁山梁旗。官・宋旗へ置き換えない。
呼延灼は黒金甲金兜黄巾、節付き硬い直線金属棒二本。黒馬四足先のみ白（鼻額無斑）、盗難後25頁以降青鬃馬へ交替。
解珍は紫褐肌長顔細腰暗紫巾、解宝は濃茶肌丸顔暗緑巾。両者成人短黒口顎髭、虎皮上衣豹皮下衣鋼叉。
鄒淵は四角顔短黒髭紺巾紺衣、鄒潤は細長顔短黒髭黒結髪後頭部丸瘤・深緑長衣。
朱仝は赤褐顔緑衣黒巾、腹より長い黒髯、本人LEFT頬のみ印。
楊雄は細黒髭黒結髪小翠花赤衣紺帯、陶宗旺は頑丈農民風茶衣鉄鍬。
劉唐は赤茶顔赤髪短髭茶赤衣、杜遷は長身暗灰巾暗灰衣短黒髭。
穆弘は長身端整短髭濃青衣黒巾、穆春は小柄短髭茶衣、兄弟朴刀。
